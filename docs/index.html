AI assistants that write into LyX and LibreOffice

ACP Assist is a pair of floating companion panels that read your document, chat, and write directly into the live editor document. All reasoning is delegated to an external agent you already trust — there is no LLM and no API key inside these apps.

Apps

Two apps, one architecture: the editor stays the single writer of truth, and the panel is a quiet chat surface that floats beside the document.

LyX ACP Assist

An assistant for LyX. It writes through the LyXServer named pipe and the application/x-lyx clipboard format, so LyX itself performs every insertion — formatting, insets, and cross-references stay intact.

  • LyX 2.5+, Windows, Linux, macOS
  • Read-only .lyx parser builds the agent's context
  • Every paste is verified against the document before it happens

LibreOffice ACP Assist

An assistant for LibreOffice — Writer, Calc, and Impress — via a small in-process UNO bridge (.oxt) with per-module adapters. Edits land as tracked changes in Writer and Calc, and every edit is one undo transaction.

  • Writer, Calc, Impress (and Draw via Impress)
  • Multiple LibreOffice instances supported
  • Live selection and cursor events update the panel

How it works

One input box, agent-decided intent. The document is never touched behind the editor's back.

  1. The editor stays the single writer of truth. The app never writes the document file directly. For LyX, inserts are pasted through LyX itself; for LibreOffice, every operation goes through UNO in a single undo transaction.
  2. You type one message. The agent decides whether to reply in chat or edit the document, and ends its reply with a small action tag the app executes mechanically:
  3. Edits are confirmed quietly and are undoable. Applied edits are confirmed under the reply ("Inserted after [p5]") and every edit is one undo step.
ActionEffect
[ACTION: none]Prose reply; document untouched
[ACTION: insert]Paste at the cursor
[ACTION: insert-after pN]Insert new paragraph(s) after [pN]
[ACTION: rewrite]Replace the active selection
[ACTION: rewrite-at pN]Replace paragraph [pN] (verified first)
[ACTION: delete-at pN]Delete paragraph [pN]
[ACTION: move pN pM]Move paragraph [pN] to after [pM]

The LibreOffice app adds module-specific actions — write-cells, insert-rows, insert-cols in Calc, and insert-after sN / rewrite-slide sN in Impress.

Bring your own agent. Any Agent Client Protocol (ACP)-speaking CLI works — vibe-acp, copilot --acp, or goose acp — configurable at runtime in the app's agent settings.

Get started

You need Node.js 22+, your editor (LyX 2.5+ or LibreOffice), and an ACP agent CLI.

Install once at the repository root, then run either app from its own directory: 

git clone https://github.com/guzmandrade-dev/lyx-acp-assist.git
cd lyx-acp-assist
npm install

cd apps/lyx          # or: cd apps/libreoffice
npm start            # builds TypeScript and launches the companion

Open a saved document in your editor, select some text, and type a message. The panel shows the active document, selection word count, and connection status. For installers, run npm run package — prebuilt installers for Windows, macOS, and Linux are attached to each release.
